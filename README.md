# 单词桥 MVP

一个围绕“快速记住单词”构建的静态网页 MVP：先确认学习者真正认识的熟词，再用熟词和目标词之间的可靠关系建立最短记忆路径，最后通过撤桥拼写和到期复习检查是否真正记住。

## 当前范围

- 首批30个高中基础目标词
- 熟词诊断与备选熟词入口
- 词形变化、记忆桥和事实边界分层展示
- 每轮5词学习与主动拼写
- 到期复习：独立记住、借助词桥找回、仍需复习
- 10分钟、1天、7天的轻量复习间隔
- 浏览器本地保存进度
- 桌面端与移动端响应式页面

当前版本不需要登录，不包含服务端数据库、付费、排行榜或复杂推荐算法。学习记录只保存在当前浏览器的 `localStorage` 中；清理浏览器数据会同时清除进度。

## 本地运行

需要 Node.js 18 或更高版本：

```powershell
npm start
```

然后访问 `http://127.0.0.1:4174/`。

## 数据校验

```powershell
npm run validate
```

校验会确认30张词卡的唯一性、必填教学字段、熟词入口、证据等级、复习间隔和发布状态。

## 发布边界

这个仓库只包含正式 MVP 所需的网页文件和已经改写、审核后进入产品的30张词卡。课程原始资料、内部知识库、候选关系、审核过程、实验报告和个人文件均不在仓库中。
